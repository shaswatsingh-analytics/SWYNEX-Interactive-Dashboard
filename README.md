## 📊 Project Overview

This project explores Netflix movies and TV shows through an interactive dashboard designed to make content insights easier to understand.

### ✨ Dashboard Features

- 📌 Key performance indicators (KPIs)
- 🎥 Movies vs. TV Shows analysis
- 📅 Content added over time
- 📈 Content distribution by release year
- 🗂️ Top genres and countries
- ⭐ Ratings distribution
- 🔎 Interactive filters for exploring content
